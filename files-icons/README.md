# Files icons bundle

A Herdr Files clone with file-type icons, folder expansion and bounded code previews.

Install mods/files-icons without overwriting an existing folder, run the native check, then open it as a tab or point a personal layout's Files block to files-icons. The optional Jira workspace layout already does so.

Reads the focused terminal's folder and file contents, watches local folders, and invokes shell/PowerShell directory listing and Git status locally or on the space's machine. It does not upload file contents to a service. It uses Herdr's editor preview and theme. The code inherits Herdr's file-count/preview limits. See the root licensing report before redistribution.
